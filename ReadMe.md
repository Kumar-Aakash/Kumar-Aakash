**Software architect — I take AI-built apps to production.**

I harden prototypes and AI-generated apps so they can actually be run: security, reliability, LLM cost metering, deployment, and wiring models into systems people already use.

## What I'm working on

- Taking AI-built and prototype apps through security hardening, reliability, and deployment
- LLM cost metering and usage visibility for production inference
- Integrating AI into existing products and internal systems

## Focus areas

- **Production AI** — moving a working demo to something that stays up, stays safe, and stays affordable
- **LLM operations** — cost metering, observability, and the unglamorous work behind model-backed features
- **AI systems** — agent workflows, model integration into existing products, and the infrastructure that keeps them running in production
